Charts are drawn on a plane and coloured from the theme, so you rarely choose a colour.

```ts
import { Scene } from '@@pkg@@';
import { bars } from '@@pkg@@/charts';

const s = new Scene({ view: 'front', size: [420, 262], padding: 6 });
s.add(bars({
  data: { Web: [12, 19, 7, 15], App: [8, 11, 14, 9] },
  labels: ['Q1', 'Q2', 'Q3', 'Q4'],
  title: 'Signups',
}));
```

Each series takes the next series colour, which is the accent turned around the colour wheel. Change the theme and the chart follows.

## Choosing colours

A palette is a name or a list of roles and colours:

```ts
import { Scene } from '@@pkg@@';
import { donut, bars } from '@@pkg@@/charts';

const s = new Scene({ view: 'front', size: [420, 262], padding: 6 });
s.add(donut({
  data: [['Done', 70], ['Open', 20], ['Blocked', 10]],
  palette: ['accent', 's2', 'faint'],        // roles, so they still follow the theme
  labelValues: true,
}));
```

- `palette: 'sequential'` runs one hue from light to strong, for values.
- `palette: 'diverging'` runs two hues around zero.
- `highlight: 2` picks one bar out in the accent and greys the rest.

## Say something with it

```ts
import { Scene } from '@@pkg@@';
import { bars } from '@@pkg@@/charts';

const s = new Scene({ view: 'front', size: [420, 262], padding: 6 });
s.add(bars({
  data: [['Rust', 82], ['Go', 64], ['TypeScript', 91], ['Python', 77]],
  horizontal: true,
  labelValues: true,
  highlight: 2,
}));
```
