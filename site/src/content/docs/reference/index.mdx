The reference is generated from the library's own TypeScript and TSDoc comments, so it always matches the code. Every function has its parameters, what it returns and a short example you can run in the playground. Looking for a name? Use the [list of all exports](/reference/all/), or the filter box at the top of any pack page.

Each pack page lists its functions alphabetically, then classes, then option types. Every option interface has a table of its properties with the type and default. Options that several functions share, such as `NodeOpts`, are listed once and linked.
